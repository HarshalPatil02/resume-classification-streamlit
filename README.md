# Resume Classification & Role Matching

A Streamlit portfolio application based on the Resume Classification notebook. It trains a text classifier to predict a resume's role category from its content using TF-IDF features and Logistic Regression.

## Features

- Upload a labelled CSV dataset containing `TEXT` and `ROLE_FOLDER` columns.
- Inspect the number of resumes, role labels, word counts, and role distribution.
- Train and evaluate a TF-IDF + Logistic Regression pipeline using a holdout split.
- Review accuracy, weighted precision/F1, a classification report, and (for up to 20 classes) a confusion matrix.
- Classify uploaded PDF, DOCX, and TXT resumes, or paste resume text.
- See the predicted role and top role matches; export batch predictions to CSV.

## Expected training data

Use the `resume_classification_datasets.csv` generated by your notebook. The required columns are:

- `TEXT`: extracted resume text.
- `ROLE_FOLDER`: role label taken from the resume's source folder.

Optional columns such as `FILE_NAME` and `LABEL` are retained in the preview but not used for model training.

**Important:** In the notebook, the `LABEL` column is always set to `Resume`. It is not the classification target. `ROLE_FOLDER` is the target label used for role classification.

## Run locally

1. Put `app.py`, `requirements.txt`, and `README.md` in one folder.
2. Open that folder in VS Code.
3. (Recommended) Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

4. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Start the app:

   ```bash
   python -m streamlit run app.py
   ```

6. Upload `resume_classification_datasets.csv` in the sidebar and click **Train classifier**.

## Deploy to Streamlit Community Cloud

1. Push `app.py`, `requirements.txt`, and `README.md` to a GitHub repository.
2. In Streamlit Community Cloud, create an app from that repository and choose `app.py` as the main file.
3. Open the deployed app and upload the labelled CSV to train the model.

The dataset is uploaded through the app rather than bundled into the repository. This helps keep personal resume information out of public GitHub commits.

## Methodology

- Text: `TEXT`
- Target: `ROLE_FOLDER`
- Vectorization: `TfidfVectorizer(stop_words="english", max_features=3000)`
- Classifier: `LogisticRegression(max_iter=1000)`
- Evaluation: random holdout split; stratification is used when every class has at least two examples.

The final prediction model is refitted on all labelled rows after evaluation. Holdout metrics are reported from the separate evaluation model.

## Limitations and responsible use

- Resume text extraction works for text-based PDFs; scanned PDFs may require OCR and may return no text.
- Performance depends on label quality, number of examples per role, and class balance. Small or underrepresented roles may perform poorly.
- The model learns patterns in historical labels and may reproduce biases in those data. Do not use predictions as the sole basis for hiring or screening decisions.
- Displayed class scores are not calibrated probabilities of job suitability.
